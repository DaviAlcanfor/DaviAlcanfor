# Design System: Davi Alcanfôr GitHub Profile

Gothic and penitent. Candlelight in a dark nave: sparse, serious, no jokes.
The cover is the only painted asset; everything else is generated by
`tools/build_assets.py` from the tokens below. Run `python tools/build_assets.py` after any
change; output is deterministic.

### Typography

GitHub serves SVGs through `<img>`, which blocks external fonts, so all SVG
text is converted to `<path>` with fontTools at build time. Fonts live in
`tools/fonts/` with their OFL licenses.

| Role | Font | Weight | Size | Tracking |
| --- | --- | --- | --- | --- |
| Name (intro) | Cinzel | 700 | 46 | 3 |
| Item and votive titles | Cinzel | 700 | 26 / 20 (15 if long) | 2 / 1.5 |
| Subtitle, epitaph, numerals | Cinzel | 400 | 17 / 22 / 13 | 2 / 3 / 2 |
| Labels (plaques, badges) | Silkscreen | 400 | 16, uppercase | 1 |

Silkscreen is a pixel font; at 16px its pixel grid is 2px, the same unit as
the sprites, so labels and pixel art share one grain. Body text in the README
stays native Markdown.

### Pixel grid

Sprites are lists of equal-length strings; each char maps to a palette color,
`.` is transparent. `sprite()` merges horizontal runs into `<rect>`s inside a
`shape-rendering="crispEdges"` group. Units: 2px for icons and labels, 3px for
votive icons and large candles, 4px for the tallest footer candle.

## Cover

`build_cover()` takes `source/cover_source.png` (falls back to
`source/cover_thumb.jpg`, the thumbnail the approved look was made from),
crops to 3:1, resizes to 240 × 80 with LANCZOS, applies gamma 0.72 then
contrast 1.45, and quantizes to the palette with 4 × 4 Bayer dithering at
strength 14. That matches `source/cover_reference.png` on ~97% of pixels.

Animation reuses `tools/cover_procedural.py` at the flame positions in
`FLAME_TIPS`: a light map whose deviation from its mean modulates brightness by
at most `GLOW` (12%) before quantization, flickering flame tips, and 22 embers
that rise and cool from gold to blood. Only the fire region changes between
frames, so the scene keeps reading as a still image.

## Rules

- **Dark backing.** Every SVG paints its own `void` background; nothing
  depends on GitHub's light or dark theme.
- **Steps, never curves.** Corners are cut in square steps; no `rx`, no
  circles.
- **Palette lock.** Only `PALETTE` colors, including in the activity workflow.
- **Motion only where it earns it.** CSS keyframes inside SVG, no JavaScript.
  Only candle flames animate (three frames, `step-end`). Frame 0 is visible by
  default, so static renderers and `prefers-reduced-motion` show a lit candle.
- **Nothing borrowed.** No characters, logos or art from Blasphemous, Souls,
  Sekiro, Valorant, Rainbow Six Siege or GeoGuessr. Language logos appear only
  as simple pixel versions.
- **Alt text.** Descriptive on every meaningful image; `alt=""` on dividers.
- **Width.** Max 840px (dividers). Text-bearing panels are 640px so their
  smallest text stays around 10px when GitHub scales them to a phone; badges
  and plaques wrap inline.
- **Voice.** English. Project text reads like an item description: short,
  sober, a little oblique, and accurate to the repository's own README.
- **Facts.** Nothing about the author that the author has not stated. No
  invented stats.

## Activity cards

`.github/workflows/activity.yml` runs daily (and on demand) and publishes to
the `output` branch:

- `stats.svg` and `top-langs.svg` via
  `stats-organization/github-readme-stats-action` (the public
  github-readme-stats instance is paused), colored with `void`, `gold_light`,
  `bone`, `crimson` and `stone`.
- `snake-dark.svg` via `Platane/snk/svg-only`, contribution levels
  `shadow → blood → crimson → gold → gold_light`, snake in `bone`.

## Previews

Render every SVG to PNG before committing and look at it:

```bash
pip install resvg-py
mkdir -p previews
python -c "import resvg_py, pathlib; [pathlib.Path(f'previews/{p.stem}.png').write_bytes(bytes(resvg_py.svg_to_bytes(svg_path=str(p), zoom=2))) for p in pathlib.Path('readmes/darksouls/assets').glob('*.svg')]"
```
